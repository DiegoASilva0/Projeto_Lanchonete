# Projeto Lanchonete

Site de uma lanchonete desenvolvido para praticar HTML, CSS e JavaScript.

O projeto possui um cardápio completo onde o cliente pode escolher produtos, adicionar ao carrinho e finalizar o pedido pelo WhatsApp.

## 🚀 Funcionalidades

- Cardápio dividido por categorias
- Lanches, pizzas, porções e bebidas
- Carrinho de compras
- Adicionar e remover produtos
- Aumentar e diminuir quantidade
- Cálculo automático do subtotal
- Carrinho salvo com LocalStorage
- Finalização do pedido pelo WhatsApp
- Layout responsivo para celular

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📱 Responsividade

O site foi desenvolvido para funcionar tanto em computadores quanto em dispositivos móveis.

## 🎯 Objetivo

Projeto desenvolvido para estudo e portfólio, com foco na prática de desenvolvimento Front-End.
